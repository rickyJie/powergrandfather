## 统计口径与限制

- **管理过的会话**是指交互式、自动化或 Agent Deck 会话创建的一条记录，
  不代表独立用户数。
- **Agent 工作时间**会分别累加并发 Agent 的工作区间，因此 354.5 Agent
  小时不等于 354.5 小时自然时间，也不能解释为生产率倍数。
- **Workflow stage 执行**是一条持久化的阶段尝试。一个 mission 可以包含
  多个 stage；必要 stage 失败会导致 mission 失败，因此 stage 成功数和
  mission 成功数回答的是不同问题。
- **反馈项**是通过私有实例反馈流程记录的问题。“已解决”表示它在该实例中
  被标记为已解决，不等于公开 GitHub issue 数量。
- 这些数字描述的是维护者私有实例和持续变化的预发布版本，证明的是长期
  自用与迭代，不是性能基准，也不承诺其他机器上的可靠性。

## 隐私边界

公开仓库没有复制任何 prompt、会话记录、仓库路径、测试者身份或数据库原始
记录，只保留了上面的聚合数字。PowerGrandFather 默认不发送公开产品遥测。
