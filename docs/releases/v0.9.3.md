# PowerGrandFather v0.9.3 — first public release

> Draft GitHub release notes. Publish these notes with a `v0.9.3` tag only
> after the public install check and CI pass.

PowerGrandFather is a local-first mission-control console for developers who
run several Claude Code or Codex CLI sessions at once. It keeps live terminals,
unattended workflows, notifications, token attribution and mobile
intervention in one browser-based tool backed by one SQLite database.

## Highlights

- Monitor multiple Claude Code and Codex CLI sessions in one browser tab, with
  working, waiting and crashed state visible in the session rail.
- Run scheduled, multi-stage workflows with declared output contracts,
  per-stage validation and crash reconciliation.
- Review file changes, rendered Markdown, source code, images and diffs from
  the session UI.
- Attribute token use by repository, model and tool; add budgets and
  natural-language alert rules.
- Receive in-app or Lark notifications and use the companion PWA when a
  session needs input away from the desk.
- Keep selected instructions, MCP configuration and skills synchronized
  between supported agents.
- Keep deployment intentionally small: one FastAPI process, one Vue SPA and
  one SQLite file.

## Evidence before public release

The maintainer dogfooded the private instance for two months across 356
sessions and more than 350 cumulative agent-hours. It recorded 103 workflow
stage executions, 95 of which succeeded, while 59 of 75 internal feedback
items were resolved. Definitions and limitations are documented in the
[dogfooding record](../dogfooding.md).

## Install

Public CI currently covers Ubuntu; other platforms are not yet part of the
compatibility guarantee. Installation requires Python 3.11+, Node 18+, conda,
and a working Claude Code and/or Codex CLI login.

```bash
git clone https://github.com/rickyJie/powergrandfather.git
cd powergrandfather
conda create -n csm python=3.11 -y
conda activate csm
pip install -e .
alembic upgrade head
npm --prefix frontend ci
npm --prefix frontend run build
./scripts/start.sh
```

Open `http://localhost:8000` after startup.

## Deliberate limits

- Single-user and local-first; this is not a hosted or multi-tenant service.
- No git-worktree isolation: sessions operate in the directories you select.
- Claude Code and Codex are the fully integrated backends in this release.
- The backend binds to `127.0.0.1` by default. Do not expose it to an
  untrusted network; remote access requires the security guidance in the
  README.
- The package and `CSM_*` settings retain the historical internal name
  “CSM” for compatibility.

## Source-history note

The public branch is a sanitized v0.9.3 source snapshot rather than the
private development repository's full history. Internal workflows,
